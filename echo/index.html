N20 Architecture

Your data stays on your machine.

A native shell, a local core and a local database. The cloud is used only for the language model, and only when it is needed.

  • Tauri 2 shell (Rust) starts a frozen Python core with a fresh random 32-byte token on every launch. The window can only show the app itself; links never navigate it to the web.
  • FastAPI core on 127.0.0.1 with SQLite and full-text search. Data lives in a private folder (mode 0700); migrations back up the database first.
  • Model router: Claude when online, a free Groq model when Claude is unavailable, and a local Ollama model with no internet. A monthly budget cap switches the cloud off.
  • Speech on device: wake word, faster-whisper speech-to-text and Kokoro text-to-speech. No audio is stored; a voice turn opens no network connection.
  • Tools over MCP: every integration's tools start at Confirm and stay hidden until you set their policy.

N30 Security

An assistant that can't be talked into things.

Built from a written threat model. Every threat maps to a control, the code that implements it and the tests that prove it, and an independent review passed it in three rounds.

ThreatControl
Prompt injection from email, notes, calendar or web textExternal content is wrapped as untrusted data and taints the turn, so any write then needs your approval. Permission tiers are enforced in code; the model cannot see or change them.
Other web pages calling the local APIToken on every request, strict Host and CORS checks, loopback-only binding.
Leaked keysKeys live only in the system keyring; a redaction filter covers logs, errors, audit rows and events; key fields are write-only.
A careless or malicious pluginExplicit trust warning, minimal environment, only its own secrets, tools start at Confirm, any change to it resets its policy.
An always-on microphoneWake word runs locally, no audio written, mute closes the stream, the microphone state is always shown in words.
Runaway cost or loopsCapped tool rounds per turn, a timeout on every model call, a monthly budget.

N50 Process

Built like a production system.

Specification first, then small tasks in order, each one closed by green checks and an independent review at every milestone gate.

01Spec pack

PRD, SRS with a threat model, architecture, and an API/database contract that changes only through a written decision.

02Decisions on record

35 ADRs, from packaging to how the local model reuses its prompt, each with what was rejected and why.

03Gated milestones

28 milestones. None passes without a full quality gate (types, lint, unit, API and end-to-end tests) and a reviewer's PASS.
